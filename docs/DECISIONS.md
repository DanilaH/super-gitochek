# Game Miner — decisions

## 2026-09-19 — D-001: хранить ручные игровые находки в репозитории

**Решение:** основной журнал *интересных идей и проверенных вручную механик* — [`GAME_IDEAS.md`](GAME_IDEAS.md). Ссылка также размещается в корневом `README.md`. При следующем скане дополнять журнал, не заменяя машинным рейтингом и не теряя ранее отмеченные кандидаты.

**Почему:** история отдельного чата и временные артефакты GitHub Actions не гарантируют полное восстановление ручных выводов в другой беседе. `data/discovery-registry.json` остаётся источником истины о факте обнаружения/инспекции репозитория, но **не** об интересности, спросе, качестве и лицензиях. README и выборочные файлы кода — ещё не запуск игры и не проверка прав.

**Границы:** не смешивать этот каталог с самостоятельными игровыми концепциями пользователя; не приписывать непроверенный коммерческий потенциал. Технические изменения майнера и решения по реализации фиксировать отдельно при их появлении.

## 2026-09-19 — D-002: сохранять поздние ручные находки без потери основного журнала

Дополнение не отменяет старые механики. Главный README указывает на оба файла. При дальнейших обзорах либо вносить новую находку прямо в основной журнал, либо добавлять новый именованный обзор и актуализировать его ссылки здесь и в README.

**Последний подтверждённый срез:** пятый скан — 115 инспекций; шестой — 130; каталог 539, очередь 10 (GitHub Actions run `35458217847`). Старое число 204 в заголовке основного журнала — исторический срез, **не текущее состояние**. Автоматическая инспекция не равна ручному аудиту качества, запуску игры, правовой проверке или исследованию спроса.

## 2026-09-19 — D-003: разбор внутри уже обнаруженных репозиториев — отдельный документ

**Продолжение D-001/D-002:** [GAME_IDEAS_DEEP_DIVE_2026-09-19.md](GAME_IDEAS_DEEP_DIVE_2026-09-19.md) документирует ручной разбор внутренних мини-игр и кодовой механики Firing Balls, 115, Boom Dots, а также ложные кандидаты. **В новом чате читать все три документа:** основной журнал, обзор 5–6 прогонов и deep dive. Ссылки на все три закреплены в README. Новый документ **не означает, что был седьмой скан**; последний подтверждённый машинный срез остаётся 539 inspected / 10 pending.

**Принцип:** отдельный модуль внутри крупного сборника считать самостоятельной игровой находкой только после просмотра его исходника или описания; отсутствие условий победы, реального merge/upgrade loop и прав на ассеты отмечать явно. Проверка кода не заменяет запуск, тест тактильности и проверку спроса.
