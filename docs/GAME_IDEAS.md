# Game Miner — проверенные вручную идеи и игровые референсы

**Обновлено:** 2026-09-19. **Статус:** живой журнал кандидатов, а не список готовых коммерческих проектов.

Этот файл — точка входа для следующего чата/агента. Сначала прочитай его, затем `docs/DECISIONS.md`, а при необходимости — `data/discovery-registry.json` и артефакты [Game Miner Actions](https://github.com/DanilaH/super-gitochek/actions/workflows/game-miner.yml). В новой беседе достаточно дать ссылку на этот файл и попросить «вспомни интересные находки Game Miner». **Не выдавать автоматически сгенерированный `score` за качество игры или спрос.**

## Что ищем и что уже проверено

Цель: компактная браузерная игра с понятным управлением, тактильным действием, заметной наградой/открытиями и минимальной производственной нагрузкой. Unity, Godot, мобильные и нативные проекты годятся как *источники механик*, но перенос может означать полную переработку. Приоритет — найти интересный игровой цикл, а не автоматически перепубликовать проект.

Ни одна игра ниже **не была собрана или пройдена** в рамках этих просмотров; выводы основаны на README и выборочной проверке файлов исходников. Спрос, удержание, реклама и пригодность для Яндекс Игр не подтверждены. Метка «MIT в README/метаданных» **не означает**, что разрешено использовать все графические, музыкальные и сторонние ассеты. Авторские права и происхождение ассетов проверять отдельно, особенно перед коммерческим выпуском.

Срез автоматического скана: [прогон №39](https://github.com/DanilaH/super-gitochek/actions/runs/35455256737), 85 новых разборов; накопленный каталог — 204 проекта, ожидают разбора 276. Артефакты Actions хранятся ограниченное время; постоянный реестр находится в `data/discovery-registry.json`. **204 — размер каталога, а не число вручную одобренных игр.**

## Содержательные кандидаты — есть самостоятельная механика для небольшого прототипа

### Plinko + idle + prestige — [`GitLomaz/plinko`](https://github.com/GitLomaz/plinko)

- **Петля:** выпуск шарика → попадание в зоны/валюта → покупка и улучшение шаров и зон → новые возможности; в `JS/game.js` обнаружены токены, престиж, сохранение, офлайн-прогресс и Phaser.
- **Что заимствовать как идею:** один шар, один вид апгрейда и открывающиеся зоны; престиж и комплексную физику не тащить в первый MVP.
- **Ограничение:** лицензия не установлена; исходники и ассеты не копировать без разрешения. Физика и полировка наград могут оказаться основной трудоёмкостью.
- **Проверка:** README + отдельные исходники; живой геймплей не запускали.

### TIDELINE — [`bridge-mind/tideline`](https://github.com/bridge-mind/tideline)

- **Петля:** заброс → поклёвка → борьба с натяжением лески (держать/отпускать на рывках) → редкий улов → продажа и улучшение снастей. В `src/gameplay/reelMinigame.js` есть логика натяжения, предупреждений и усталости рыбы.
- **Что пробовать:** короткую 2D-мини-игру борьбы и эффектное получение рыбы разных редкостей, а не полный Three.js-симулятор. README заявляет 21 вид и 4 локации — **не** объём нашего MVP.
- **Ограничение:** заявлена MIT, но лицензии внешних компонентов и права на ассеты требуют отдельной проверки; полная 3D-реализация дорога.

### Artifact — [`Svartskogen/Artifact`](https://github.com/Svartskogen/Artifact)

- **Петля:** артефакт постепенно теряет здоровье → игрок собирает фрукты → приносит их к объекту → продлевает его жизнь. Это подтверждено в [`Artifact.cs`](https://github.com/Svartskogen/Artifact/blob/master/Assets/Scripts/Artifact.cs) и [`PlayerBackpack.cs`](https://github.com/Svartskogen/Artifact/blob/master/Assets/Scripts/Player/PlayerBackpack.cs).
- **Что пробовать:** маленькое поле, один ресурс, явная угроза проигрыша, короткие разблокировки между попытками. Не воспроизводить полный Unity/WebGL-проект.
- **Ограничение:** 72-часовой геймджем-проект, в README указана MIT; полноту геймплея и права на каждый ассет не проверяли.

### Wind-Up Racer — [`EdmarDev/Wind-Up-Racer`](https://github.com/EdmarDev/Wind-Up-Racer)

- **Петля:** пройти три круга, собирая шестерёнки, чтобы машина не остановилась. В исходниках есть отдельный [`Winder.gd`](https://github.com/EdmarDev/Wind-Up-Racer/blob/master/src/vehicle/Winder.gd) для раскручивания/завода.
- **Что пробовать:** компактное управление движением и топливом: рискнуть ради подбора или выбрать безопасную траекторию. Можно заменить гонку другим сюжетом — это **гипотеза дизайна**, не часть оригинала.
- **Ограничение:** в корне есть LICENSE; текст и ассеты перепроверить при переносе. Геймплей не запускали.

### Coffee Shop Game — [`JustKesha/coffee-shop-game`](https://github.com/JustKesha/coffee-shop-game)

- **Петля:** перетащить или налить кофе/молоко → получить оценку совпадения пропорций с заказом. README описывает 2 ингредиента и 5 напитков.
- **Что пробовать:** короткую тактильную работу с оплатой за точность внутри *своей* игры о заработке/выживании. Отдельная мета-прогрессия потребуется: в исходном прототипе не подтверждена.
- **Ограничение:** Godot-проект на паузе; MIT фигурировала в метаданных, но текст лицензии и ассеты независимо не проверены.

## Правила пополнения

Для **каждой** новой идеи сохранять: точный `owner/repo` и URL; наблюдаемую механику с источником (README/путь к коду/ссылка на геймплей); потенциальный *собственный* MVP; production burden; подтверждённый текст лицензии и отдельно права на ассеты либо «не проверено»; факт запуска/тестирования; решение «изучать / прототип / отложить» с объяснением. Не подменять факты фантазиями о метриках и не превращать количество GitHub stars в оценку рынка.

Следующий шаг перед выбором конкретной игры: запустить 2–3 лучших кандидата, проверить ощущения и платёжеспособный/рекламный спрос на целевой площадке; **этот файл не заменяет рыночную проверку**. Пользовательские идеи из других проектов (например, отдельные концепции мини-игр) сюда не добавлять без явного решения — этот журнал посвящён находкам Game Miner.
