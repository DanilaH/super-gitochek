Источник: [седьмой контрольный скан](CONTROL_SCAN_07_2026-09-20.md), [эксперимент поиска](SEARCH_EXPERIMENT_2026-09-20.md), повторный живой GitHub repository search `phaser incremental/fishing/mining game in:name,description`, страницы 1 по 30 результатов. Это **ручной выборочный аудит**, не ещё один массовый запуск майнера. Автоматический реестр и `pending` не изменяли: вручную изученный здесь репозиторий может по-прежнему находиться в машинной очереди. Проверены README, деревья и выборочные исходники, **ни одна игра не запускалась и не тестировалась на тактильность, производительность или спрос**. Все оценки стоимости ниже — гипотезы о выделенной механике, не об оригинальном проекте. GitHub-репозиторий не даёт автоматически разрешения использовать его код, графику, звук или товарные знаки.

## Вывод для production-burden-first исследования

Из доступной выборки выделились четыре разные короткие идеи, которые можно проверить отдельно: **один точный клик в тайминге** ([Fish Catcher](https://github.com/vectorless/fish-catcher/blob/main/src/controllers/FishingController.js)), **непрерывный hold/release для удержания цели** ([Lucky Fisher](https://github.com/d2658182-hub/lucky-fisher/blob/main/src/screens/gameplay-screen.js)), **ритмический рисунок/паузы разных видов рыбы** ([Reel & Riff](https://github.com/brocahontaz/reel-and-riff-web/blob/main/src/game/rhythm.ts)), **поиск скрытых зон магнита и редкие находки** ([Kindworks Magnet Fishing](https://github.com/kindworksgames/kindworks-magnet-fishing/blob/main/src/game.js)). Эти четыре игры НЕ следует объединять в один MVP: это альтернативные способы сделать ловлю тактильной, а не список обязательных фич. У них пока нет независимого подтверждения спроса на Яндекс Играх. Не путать качество README/кода с удовольствием от живого геймплея.

## Следующий минимальный эксперимент, не новый слой майнера

Одноэкранная собственная *функциональная* демонстрация с простой условной рыбой и тремя **взаимоисключающими режимами** input: A — разовый точный клик (Fish Catcher), B — непрерывный контроль hold/release (Lucky Fisher), C — короткий рисунок note/rest (Reel & Riff). Один и тот же placeholder loot/reward UI во всех режимах, без десятков видов, магазина, open world или прогрессии. Дать людям сыграть по несколько заходов, записать субъективное желание повторить, понятность проигрыша и число добровольных повторов; затем выбрать **один** core loop. Реальную коллекцию/апгрейд добавлять лишь после подтверждения ощущений. Альтернативная, отдельная проверка — магнит в скрытые точки с 8 предметами и без дневного лимита. Это **план проверки**, в этом исследовании прототипы не создавались. Спрос Яндекс Игр — независимый вопрос и пока не измерен.
